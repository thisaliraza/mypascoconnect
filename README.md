# MyPascoConnect Login Guide

A free, open-source informational guide site for **Pasco County Schools** students, parents, and staff to learn how to use the **MyPascoConnect** portal.

## Live Site

Hosted on GitHub Pages: `https://<your-username>.github.io/mypascoconnect`

## What This Site Covers

- Step-by-step login instructions
- Overview of available features (Canvas, Office 365, Digital Textbooks, LaunchPad)
- Troubleshooting common login problems
- FAQ for students, parents, and staff
- Quick reference card

## Who Is This For?

| Role | Info |
|------|------|
| 🎒 Students | Log in with Student ID + LDAP password |
| 👩‍🏫 Teachers & Staff | Use school credentials; call 813-794-2859 for help |
| 👪 Parents | Use the myStudent parent portal for child credentials |

## How to Deploy on GitHub Pages

1. **Fork or clone** this repository
2. Go to your repository **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)` folder
4. Click **Save**
5. Your site will be live at `https://<your-username>.github.io/mypascoconnect`

- ✅ SEO-ready (meta tags, Open Graph)
